# BikeCadastro PRO

Sistema Streamlit para cadastro e gerenciamento de bicicletas.

## Executar
```bash
pip install -r requirements.txt
streamlit run app.py
```

O banco de dados local é `bicicletas.csv`. As imagens do dashboard foram alteradas para imagens de bicicletas e são carregadas pelas URLs configuradas no `app.py`.
